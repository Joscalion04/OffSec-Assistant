# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in OffSec Assistant itself — such as a
prompt injection that could bypass the scope gate, a command injection in shell
scripts, or any other issue that could be exploited against users of this tool —
please report it **privately** before disclosing it publicly.

**Contact:** joscalion04@gmail.com  
**Subject line:** `[SECURITY] OffSec-Assistant — <brief description>`

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

You will receive a response within **72 hours**. Please do not open a public
GitHub issue for security vulnerabilities until a fix has been released.

## Ethical Use Reminder

This tool is designed exclusively for **authorized security testing**. Any use
against systems without explicit written authorization from the system owner is
illegal and violates this project's License.
